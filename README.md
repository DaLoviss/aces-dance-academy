# Aces Dance Academy

Build a multi page website named ACES Dance Academy, where the aim is to provide an environment to showcase the talented dancers, advertise the dance company inviting persons to embrace their inner dancer and register. The website should serve as their primary hub in relation to their other social media presence.

Pages to create should include;

Home, About Us, Media, Upcoming Events

Information to populate those pages can be found in their social media pages;

https://www.facebook.com/acesdanceacademy/about

https://www.instagram.com/acesdanceacademy?lqvp=bHVtMm82N3U1OGdi

The logo for the website can be the same exact logo found on their facebook page
